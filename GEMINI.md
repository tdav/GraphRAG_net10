# Контекст проекта: GraphRAG_net10

Этот файл содержит контекст и инструкции для ИИ-агентов, работающих над системой GraphRAG для здравоохранения.

## 🩺 Обзор проекта
GraphRAG_net10 — это специализированная система Retrieval-Augmented Generation (RAG), построенная на **.NET 10**. Она объединяет **граф знаний** (Apache AGE) и **векторный поиск** (pgvector) в единую платформу на базе PostgreSQL для обеспечения объяснимого ИИ (XAI) при поддержке принятия клинических решений.

## 🛠 Технологический стек
- **Среда выполнения**: .NET 10 (C#)
- **База данных**: PostgreSQL 17/18
  - **Расширения**: `age` (графы), `vector` (эмбеддинги), `pgcrypto`, `pg_trgm`, `uuid-ossp`.
- **AI/ML**: 
  - **Microsoft Semantic Kernel**: оркестрация.
  - **ONNX Runtime**: инференс GNN-моделей (архитектура GAT).
  - **Azure OpenAI**: эмбеддинги и чат.
- **Стандарты**: **HL7 FHIR R4** для представления медицинских данных.
- **Архитектура**: **Clean Architecture** (Domain, Application, Infrastructure, Api).

## 📂 Ключевые директории
- `src/GraphRAG.Domain`: сущности (Core, Medical, Graph, AI), интерфейсы и события.
- `src/GraphRAG.Infrastructure`: контекст БД, репозитории (AGE, pgvector) и миграции.
- `src/GraphRAG.Application`: бизнес-логика, DTO и сервисы.
- `src/GraphRAG.Api`: контроллеры, настройка DI и документация OpenAPI.
- `docs/`: технические спецификации и поэтапные планы.

## 📝 Рекомендации по разработке
1.  **Медицинские стандарты**: всегда придерживайтесь правил маппинга FHIR R4. Используйте SNOMED CT, LOINC и RxNorm для терминологии.
2.  **Графовая логика**: операции с графом знаний должны использовать **Apache AGE (openCypher)**. Избегайте чисто реляционных соединений (joins) для сложных связей.
3.  **Векторный поиск**: используйте оператор `<=>` (косинусное расстояние) для поиска по сходству векторов в PostgreSQL.
4.  **Мультитенантность**: строго соблюдайте **Row Level Security (RLS)** во всех запросах к базе данных, используя `tenant_id`.
5.  **Объяснимость (XAI)**: каждый ответ должен пытаться предоставить «путь рассуждения» (узлы и ребра подграфа), который повлиял на результат LLM.
6.  **Стиль кода**: следуйте установленному паттерну Clean Architecture и используйте возможности .NET 10 / C# 13 (records, primary constructors и т.д.).

## 🤖 Инструкции для ИИ-агента
При работе с этим проектом:
- Приоритетной задачей является замена заглушек реальными реализациями в `GraphRAG.Infrastructure`.
- Убедитесь, что все медицинские сущности корректно сопоставлены между FHIR и графом знаний.
- При написании Cypher-запросов используйте `ag_catalog.cypher` с правильной параметризацией.
- Всегда проверяйте файлы `IMPLEMENTATION_STATUS.md` и `new_plan.md` перед предложением изменений.
