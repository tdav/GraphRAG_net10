🎯 КЛЮЧЕВЫЕ ТЕХНОЛОГИИ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Backend Framework:
  • .NET 10 (C#) - современная платформа
  • ASP.NET Core - для REST API

AI & ML:
  • Microsoft Semantic Kernel 1.30+ - оркестрация AI агентов
  • ONNX Runtime 2.0+ - инференс GNN моделей
  • GraphSAGE/GAT - архитектуры GNN
  • Azure OpenAI / OpenAI - LLM для генерации

Database & Search:
  • PostgreSQL 18 - основная БД
  • Apache AGE 1.7+ - графовый движок (openCypher)
  • pgvector 0.8+ - векторный поиск (HNSW)

Healthcare Standards:
  • HL7 FHIR R4 - стандарт медицинских данных
  • SNOMED CT, LOINC, RxNorm - терминологии

✨ КЛЮЧЕВЫЕ ОСОБЕННОСТИ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Гибридный поиск
   Vector search (pgvector) + Graph search (Apache AGE)

2. Графовые нейронные сети (GNN)
   Ранжирование узлов и ребер для фильтрации шума

3. Объяснимый ИИ (XAI)
   Визуализация reasoning path через attention weights

4. FHIR Integration
   Автоматический маппинг FHIR Resources → Graph

5. Multi-tenancy & Security
   Row Level Security (RLS) для изоляции данных
