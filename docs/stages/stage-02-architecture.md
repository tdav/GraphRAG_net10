# Архитектура GraphRAG_net10

В этом документе представлена архитектура проекта GraphRAG_net10, который состоит из нескольких слоев:

## Слои архитектуры

1. **API**: Этот слой предоставляет интерфейсы для взаимодействия с клиентом. Он обрабатывает входящие запросы и отвечает на них, используя контроллеры.

2. **Application**: Данный слой отвечает за бизнес-логику приложения. Он управляет взаимодействием между слоями и контролирует выполнение операций.

3. **Domain**: Слой, содержащий основные бизнес-сущности и правила. Здесь находятся классы и интерфейсы, отражающие бизнес-модель приложения.

4. **Infrastructure**: Этот слой обеспечивает взаимодействие с внешними системами и ресурсами, такими как базы данных, файловые хранилища, веб-сервисы и пр.

## Основные сущности

- **Пользователь**: Сущность, представляющая пользователей системы.
- **Проект**: Сущность, связанная с конкретной работой, выполняемой пользователями.
- **Задача**: Сущность, представляющая отдельные задачи, которые пользователи должны выполнять в рамках проекта.

## Взаимодействия

- API взаимодействует с слоем Application для обработки запросов.
- Application слой взаимодействует с Domain для выполнения бизнес-логики.
- Domain может обращаться к Infrastructure при необходимости доступа к данным.
